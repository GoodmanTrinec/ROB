# Roadmap

## v0.1 — Mobile base
- PC ↔ Raspberry Pi communication
- Raspberry Pi ↔ ESP32 communication
- motor control
- emergency STOP
- camera
- microphone
- speaker
- basic voice commands
- watchdog and fail-safe stop

## v0.2 — Odometry and obstacle sensing
- wheel encoders
- battery telemetry
- ToF / ultrasonic sensors
- controlled distance movement
- controlled rotation

## v0.3 — Navigation
- LiDAR
- SLAM
- room map
- autonomous navigation
- return-to-home

## v0.4 — Vision
- object detection
- person detection
- dog detection
- visual search
- room awareness

## v0.5 — AI agent
- natural language tasks
- multi-step plans
- tool calling
- memory of rooms and objects
- Home Assistant integration

## Later
